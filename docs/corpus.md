# 语料与来源

`README` 只讲怎么用，这里讲**数据是什么、从哪来、为什么是这些**。

## 总览

| 文件 | 规范 | 性质 | 条文 | 解读 | 可判 |
|---|---|---|---|---|---|
| `gb55037-2022.yaml` | 建筑防火通用规范 | 强制性国标 | 238 | 238 | 1 |
| `gb55031-2022.yaml` | 民用建筑通用规范 | 强制性国标 | 142 | 142 | 0 |
| `gb55038-2025.yaml` | 住宅项目规范 | 强制性国标 | 122 | 122 | 2 |
| `gb55019-2021.yaml` | 无障碍通用规范 | 强制性国标 | 108 | 108 | 0 |
| `gbt50001-2017.yaml` | 房屋建筑制图统一标准 | 推荐性国标 | 11 | 11 | 10 |
| `sjd-2016.yaml` | 设计文件编制深度规定 | 行政规范性文件 | 5 | 5 | 5 |
| **合计** | | | **626** | **626** | **18** |

「可判」指条文带 `machine.checkable`，能挂上可执行规则。18 / 626 = 2.9%——这个比例是诚实的，
不是没做完。

有意思的是分布：**制图标准几乎全能判**（11 条里有 10 条），因为它管的是图层名、字高、线宽
这些图上直接存在的属性；而三本 GB 55xxx 强条加起来只有 3 条能判，因为它们的条文多在讲
"应当如何布置""应当满足什么性能"，那是设计判断，不是测量。

## 逐本

**GB 55037-2022《建筑防火通用规范》**，238 条，全 12 章。全文强制，"全部条文必须严格执行"。
来源是河南省消防救援总队法规页上的 PDF（`scripts/ingest_pdf.py` 切分）。防火分区、疏散距离、
楼梯间形式，平面图最常被退图的地方都在这本。

**GB 55031-2022《民用建筑通用规范》**，142 条，6 章 27 节。**这是平面图最常对着改的一本**，
数值密集：梯段净宽按每股人流 0.55m 计、平台宽不应小于 1.20m、梯段净高不应小于 2.20m、
踏步 2～18 级、走廊不应小于 1.30m。

**GB 55038-2025《住宅项目规范》**，122 条，7 章 18 节。2025-05-01 起实施，同时废止了
GB 50096-2011 的一大批条文。跟平面图最贴近的是 4.1 套内空间（17 条）和 4.2 公共空间
（13 条）。注意 4.2.2 的楼梯踏步 0.26/0.175 与 GB 55031 表 5.3.9 的住宅行是同一个数，
两本在这里咬合。

**GB 55019-2021《建筑与市政工程无障碍通用规范》**，108 条，5 章。坡道坡度、门净宽、
扶手高度这类数字，画图时最容易漏。

**GB/T 50001-2017《房屋建筑制图统一标准》**，11 条。线宽系列、字高下限、轴号圆直径、
轴号方向、禁用 I/O/Z、附加轴线分数形式、图层命名。**管"画得对不对"**。

**《建筑工程设计文件编制深度规定》（2016 年版）**，5 条。尺寸、标高、比例、指北针。
**管"该有的内容有没有"**。

> 这两类是本质区别：一张图可以一处制图错误都没有，却因为完全没标尺寸而无法施工。
> 混成一个"合规性"分数，agent 就会在缺尺寸时还自信地说"符合规范"。

## 附表

7 张，放 `data/tables/*.yaml`：表 4.0.1 线宽组、表 5.3.9 楼梯踏步、表 5.6.4 厕所隔间、
表 7.4.1 单出口公建规模、表 7.4.7 每 100 人疏散净宽、表 3.1.2 日照标准、表 3.2.6 外墙至
道路距离。

条文正文只写「应符合表 X 的规定」，数值不在这里面的那一条，对 agent 就是一句空话。
所以表被单独转录一份，`cadspec kb show` 会把挂靠的表一起打出来。

表为什么不塞回 `data/kb`：kb 里的条文要与原文逐字一致，而同一张表常被多条条文引用，
也要能被规则单独查询。`kb verify` 会检查每张表挂靠的条文确实存在、表头与数据行列数对得上。

## 有意不录的

表 5.0.2 字高表与附录 B 常用图层名称：前者可由 §5.0.7 的 2.5mm 下限推出结论，后者的
权威词表要逐条抄、收益低。

GB 55037 表 10.1.4、10.1.5 与 GB 55038 表 2.2.6、3.1.1、3.2.7、6.1.1、6.2.3、7.4.1、
7.4.5：消防电气、声环境、照度、负荷等级，跟平面图上的墙柱门窗无关。

**这是取舍不是遗漏。** 没录的表在 `scripts/list_tables.py` 里能查出来，将来要用随时补。

## 条文是怎么进来的

五百多条不是手抄的，有两条链路，都只做机械部分。

**PDF**（`scripts/ingest_pdf.py`）：适合政府站点发布的可复制 PDF。

```bash
pip install pymupdf
python scripts/ingest_pdf.py 规范.pdf \
    --standard GB55037-2022 --name 建筑防火通用规范 \
    --source-url https://ha.119.gov.cn/2025/04-16/3491624.html \
    -o data/kb/gb55037-2022.yaml
```

**HTML**（`scripts/ingest_html.py`）：住建部官方 PDF 多数是扫描件——GB 55031 的官方附件
24 页只有 888 个水印字符，GB 55019 的 20 页只有 740 个，一个字都抽不出来。这种改从
按节发布的 HTML 页抓正文。

```bash
python scripts/ingest_html.py \
    --list https://gf.cabr-fire.com/list-1535.htm \
    --standard GB55031-2022 --name 民用建筑通用规范 \
    --source-note "官方 PDF 为扫描件，正文取自分章 HTML 页" \
    -o data/kb/gb55031-2022.yaml
```

三个坑记在这里，改脚本前先看：

1. **公告的废止清单也带条文号**。不处理会切出一条假的 `3.2.1`，内容是「条。二十九、
   《精细化工企业工程设计防火标准》GB 51283-2020 第4.1.5、4.2.9、」。脚本以总则第一条
   （`1.0.1`）为正文起点把它挡在外面。
2. **HTML 把正文和条文说明放在同一容器，二者都用条文号开头**。不截断会撞号，还会把
   说明文字当成条文原文。脚本在「条文说明」处截断。
3. **容器内有嵌套 `<div>`**。非贪婪正则只能拿到第一条（当时 266 条里 161 条重复），
   必须做标签配对计数。

`interpret` 与 `machine` 留空给人填——一条条文在讲什么、对应图上哪个对象、能不能程序化
判定，这些机器抄不出来。解读用 `scripts/patch_interpret.py` 从 `patches/*.json` 合并回去，
**因为重跑 ingest 会覆盖 YAML，补丁必须单独存档**。

## 版权边界

**仓库里没有任何标准全文、图集 PDF、扫描件或截图。**

- 条文只做为实现技术判定所必需的短摘录，逐条附官方来源链接；
- 图片表格按"数值关系"转录，不复制版式；
- 国家建筑标准设计图集（22G101 等）著作权归中国建筑标准设计研究院，其公开声明从未授权
  以图集为内容制作电子文件传播，因此本项目**永不收录**图集内容。

正式审图请以正式出版版本为准。
